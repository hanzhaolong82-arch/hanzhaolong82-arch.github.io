小猿 AI 一对一不是一个新的学习工具，而是一堂由 AI 老师全程教授的一对一课程。我负责把这项看不见的能力，设计成学生能够理解、信任并持续使用的体验。

ROLEUX / UI Designer
SCOPE角色、规划、课堂、规范
TYPE0 → 1 产品设计
核心设计命题不是让界面看起来更像 AI，而是让 AI 的每一次判断都像老师的行为。
DESIGN THESIS

AI 在后台计算，
老师在界面里行动。

算法可以完成诊断、推荐和讲解，但学生看到的不能只是一个结果。UI 的任务，是把这些能力转译成有身份、有原因、有节奏的老师行为。

01 / PRESENCE

看见老师

用角色状态、语音和动作建立稳定的教学身份。

02 / REASON

理解定制

让每一节推荐都有来处，让学习路径能够被解释。

03 / FOCUS

保持专注

让帮助在正确时机出现，但不夺走解题的主任务。

START WITH A MOMENT

先从课堂里的
8 秒停留开始。

学生卡在一道题上。传统工具等待点击，真人老师会观察、判断，再给一句恰到好处的提醒。这个瞬间定义了整个产品的 UI 逻辑。

01题目保持第一视觉层
02角色用短动作表达“我注意到了”
03一句语音提示，不直接给答案
04完整讲解由学生主动展开
01
PRESENCE SYSTEM

先让 AI
成为一位老师。

温度不是一个可爱头像，而是角色在不同教学任务中始终做出正确、克制并可理解的反应。

ROLE STATES

一个角色，
多种教学状态。

角色不靠频繁出现建立存在感，而是通过姿态、位置、语言和动作表达当前教学意图。

COMPANION STATE

陪伴状态

用于规划、等待和鼓励。坐姿、位置退后，让学生感受到老师在场但不被打扰。

APPEARANCE

只在教学节点出现

计划生成、学生停留、讲解开始和任务完成，是角色建立关系的关键时刻。

POSITION

位置表达参与程度

陪伴时退后，教学时进入内容侧边，任何状态都不遮挡题目和操作。

MOTION

动作表达状态，不表达情绪噪音

出现、思考、鼓励均控制在短时段内，并支持减少动态效果。

VOICE

一句引导，而不是一段播报

语音帮助学生继续思考，完整讲解始终由学生主动打开。

02
VISIBLE PERSONALIZATION

让每一次定制，
在界面上留下痕迹。

推荐不是一张课程表。它需要解释为什么是这一节、为什么是现在，以及完成后会去哪里。

LEARNING PLAN

把后台推荐，
变成一条看得懂的学习路径。

通过规划生成、当前任务和后续安排三个层级，让“系统给出的结果”变成“为我设计的计划”。

01 · WHY

规划生成的仪式感，证明课程是为当前学情创建的。

02 · NOW

最近一节课获得最高层级，减少用户寻找下一步的成本。

03 · NEXT

时间轴让课程之间产生连续关系，而不是孤立卡片。

COURSE LIFECYCLE

设计一张卡片，
更要设计它的一生。

课程会经历未生成、待开课、进行中、完成、取消和中途退出。状态系统让用户始终知道当前发生了什么、下一步能做什么。

层级当前可行动状态最突出
一致时间、课程和状态位置稳定
容错取消、过期和退出均有清晰反馈
03
ATTENTION SYSTEM

把课堂的注意力，
还给正在思考的学生。

AI 能提供很多信息，但课堂 UI 的价值，是决定现在什么不应该出现。

CLASSROOM FRAMEWORK

先固定课堂骨架，
再让内容动态变化。

题型、讲解和反馈不断变化，但题目、操作和角色的空间关系保持稳定，让学生不必反复理解页面。

01

题目是主任务

最高对比度和最大内容面积始终留给当前题目。

02

反馈就近出现

提示与对应内容保持空间关联，减少视线跳转。

03

老师保持在侧

角色与任务同场，但不进入主要操作路径。

QUESTION SYSTEM

不同题型，
同一套课堂秩序。

题干、作答、反馈与老师在统一框架中组合，避免每道题都成为一个新的页面。

GEOMETRY · OPEN INPUT

图形题

图形与题干同区呈现，答案区域保持足够空间，老师在侧边等待介入。

01题干区保持稳定
02内容区按题型伸缩
03操作区贴近当前输入
04反馈在问题附近出现
TEACHING LANGUAGE

把模型推理，
改写成教学语言。

界面不仅显示 AI 说了什么，还要帮助学生判断应该看哪里、理解什么、做哪一步。

HIGHLIGHT

意图不同，视觉不同

提及、提问和强调使用不同层级，避免所有重点同时抢注意力。

先观察这两个条件，你觉得哪里发生了变化？
记住：速度 × 时间 = 路程
REWRITE

从系统表达，到学生表达

隐藏模型推理过程，只输出学生当下能够继续行动的一句话。

根据约束条件执行反向推理并验证变量关系。
先把已知条件圈出来，我们从最后一步往回想。
ADD / REMOVE

内容变化，布局不跳

动态信息进入和退出时，题目位置与操作区保持稳定。

已知条件老师刚刚补充的提示下一步操作
04
CONTINUITY SYSTEM

一堂课结束，
学习仍然继续。

完成感负责情绪收束，知识总结负责认知收束，再把学生带回下一次计划。

AFTER CLASS

同时设计完成感，
和可回看的成长。

结束页面不继续堆叠信息；总结页面则重新组织知识点，让本次学习成为下一次规划的依据。
